# Projeto_pi_web

Este repositório contém a documentação e o código do frontend do Grupo 10.

## 📁 Estrutura do Repositório

- `docs/`: Documentação do projeto com os requisitos.
- `frontend/`: Código-fonte da aplicação web (Vite + React + TypeScript).

---

## 🚀 Como Executar o Projeto Frontend

Siga os passos abaixo para baixar as dependências e rodar o projeto localmente:

### 1. Acesse a pasta do projeto

No terminal, entre no diretório `frontend`:

```bash
cd frontend
```

### 2. Instale as dependências

Execute o comando para baixar os pacotes do projeto:

```bash
npm install
```

### 3. Inicie o servidor de desenvolvimento

Rode a aplicação localmente:

```bash
npm run dev
```

Após executar o comando acima, o terminal disponibilizará o endereço local (geralmente [http://localhost:5173](http://localhost:5173)) para visualizar o projeto no seu navegador.
