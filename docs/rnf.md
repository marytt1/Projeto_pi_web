| ID | Critério | Descrição |
| :--- | :--- | :--- |
| **RNF01** | Responsividade | O front-end da loja deve ser perfeitamente utilizável em dispositivos móveis e desktops. |
| **RNF02** | Segurança de Acesso | A API deve proteger as rotas da gerência utilizando tokens JWT, bloqueando usuários sem privilégios. |
| **RNF03** | Persistência Relacional | Os dados da loja devem ser obrigatoriamente armazenados de forma estruturada (ex: MySQL), com integridade referencial nas chaves estrangeiras. |
| **RNF04** | Desempenho de API | As consultas de frete e pagamento devem ocorrer de forma assíncrona para não travar a interface do usuário. |
| **RNF05** | Hospedagem em Nuvem | O banco de dados e o back-end devem ser implantados e configurados em um provedor de nuvem para garantir alta disponibilidade. |
